**Subject:** INTCEC 2026 workshop — install one app so you can run AI agents live

Dear colleague,

Thank you for registering for **"Agentic AI as a System for Engineering Research"** at INTCEC 2026. In the hands-on portion you will run a complete three-stage research pipeline — literature scan → data analysis → drafted manuscript section — on your own laptop, with every output saved as real files (tables, code, figures, a Word document). Please complete this setup beforehand:

**1. Install the Claude desktop app** (macOS or Windows): https://claude.ai/download

**2. Sign in with a paid Claude plan.** The hands-on uses Claude Cowork, which is included on all paid plans (Pro, $20/month, and up) but not the free tier. If you don't have a paid plan and don't wish to get one, still come — the exercises work well in pairs, and a free open-source alternative version (Google Colab) will be available.

**3. Two-minute test:** create an empty folder named `intcec-workshop`, open Cowork in the app, select that folder, and ask Claude: *"Create a file called hello.md with one sentence about AI agents."* If a file appears in the folder, you're ready.

**4. Optional:** bring a research topic you'd like a mini literature review on — you'll point an agent at it.

Windows note: requires Windows 10 v1909+ or Windows 11 with Hyper-V enabled.
